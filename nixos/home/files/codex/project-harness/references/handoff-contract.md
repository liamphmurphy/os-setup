# Specialist handoff contract

Every delegated task should include:

```text
Role:
Objective:
Acceptance criteria:
Relevant files and boundaries:
Known constraints:
Dependencies or contracts:
Required verification:
Stop and ask when:
```

Every specialist result should include:

```text
Status: complete | partial | blocked
Summary:
Changed files:
Tests/checks run:
Results:
Assumptions:
Risks or follow-ups:
Questions for the tech lead:
```

The lead should reject handoffs that omit verification or leave the status unclear.
